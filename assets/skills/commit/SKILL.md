# Skill: commit

## Когда использовать
Когда разработчик просит создать коммит, «закоммить изменения» или подготовить
сообщение коммита.

## Формат сообщения
```
<TICKET>: <subject>
```

- **subject**: без точки в конце, до ~72 символов.
- **TICKET**: номер задачи. Извлекается из имени git-ветки
  (например `feature/ABC-123-...` → `ABC-123`). Если не найден — спросить у разработчика.


## Сообщение от пользователя

Разработчик может передать текст в запросе — например:
«закомить с сообщением add dark mode» или «commit: fix cart total».

**Только subject** — короткий текст без тикета:
- `[TICKET]` — из имени ветки.
- `subject` — текст пользователя (без точки в конце).

## Шаги

### Если пользователь передал текст сообщения
1. Узнай имя ветки: `git rev-parse --abbrev-ref HEAD`.
2. Извлеки тикет из ветки (если нужно дополнить сообщение).
3. Собери итоговое сообщение по правилам раздела «Сообщение от пользователя».
4. Посмотри изменения: `git status` и `git diff --staged` (если ничего не
   застейджено — `git diff`).
5. Покажи сообщение разработчику и создай коммит через HEREDOC.

### Иначе — сформируй сообщение сам
1. Узнай имя ветки: `git rev-parse --abbrev-ref HEAD`.
2. Извлеки номер тикета из имени ветки. Если не найден — спроси у разработчика.
3. Посмотри изменения: `git status` и `git diff --staged` (если ничего не
   застейджено — `git diff`). Определи `subject` по характеру изменений.
4. Сформируй сообщение по формату выше.
5. Покажи сообщение разработчику и создай коммит через HEREDOC.

## Примеры

Ветка: `feature/ABC-451-add-dark-mode`, изменения в теме `ui-kit`:
```
ABC-451: add dark mode toggle to theme provider
```

Ветка: `bugfix/ABC-789-wrong-total`, исправление в корзине:
```
ABC-789: correct order total calculation
```

Пользователь: «закомить с сообщением add dark mode», ветка `feature/ABC-451-add-dark-mode`,
изменения в `ui-kit`:
```
ABC-451: add dark mode
```

Пользователь: «закомить: fix(cart): correct order total [ABC-789]», ветка `bugfix/ABC-789-wrong-total`:
```
ABC-789: correct order total
```
