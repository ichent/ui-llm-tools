# UI-KIT через MCP

Если вопрос про компоненты UI-KIT (DF / Plasma), пропсы, свойства, API, примеры, stories или вёрстку по именам компонентов:

1. Сначала вызвать MCP **ui-kit-paths**: `search_components` / `get_component` / `get_source_paths`.
2. Исходники читать через отдельный **Bitbucket** MCP по `kit` + `paths` из `get_source_paths`.
3. Не отвечать пропсы по памяти; не читать весь `index.json` в контекст вручную.
4. Если компонента нет в реестре — сказать об этом, не выдумывать.
5. При коллизии имён приоритет у DF, если пользователь не указал kit.

Ключевые запросы: «свойства Divider», «как использовать SearchInput», «собери вёрстку по структуре».
